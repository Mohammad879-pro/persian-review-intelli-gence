# Persian Review Intelligence

An NLP and machine learning
project for analysis sentiment
in Persian customer reviews.

## Project  Goal

The goal of this project is to
build a machine learning system
that classifies Persian customer
reviews into sentiment
categories.

## Planned Featuers

- Persian text preprocessing 
- Exploratory data analysis
- TF-IDF feature extrantion
- Sentiment classification
- Model evaluation and comparison
- Interactive web interface
- Online deployment
  
## Technology Stack

- Python
- Pandas
- Scikit-learn
- Matplotlib
- Streamlit

##  Project Status

Stage 1: Repository and project
setup.

## Dataset

The dataset source and its usage
permissions will be documented
before it is used in the project.

## Limitations

Predictions may be incorrect.
Model performance will be
evaluated and documented using
appropriate metrics.
